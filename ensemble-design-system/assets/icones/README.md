# Ícones

22 ícones de traço, 24×24, `stroke-width` 2, pontas e cantos redondos, sem preenchimento. Tinta fixa `encre` (#1b2545) nos arquivos, porque `<img>` não herda cor; para outra cor, copie o `<path>` para um SVG inline com `stroke="currentColor"` (classe `.en-icone`).

- Referências francesas (usar com moderação, uma ou duas por seção): `croissant`, `boina`, `torre-eiffel`, `baguette`, `cafe`.
- Aula e estudo: `livro`, `caderno`, `lapis`, `balao`, `microfone` (pronúncia), `fone` (escuta), `online`, `pessoas`.
- Interface: `calendario`, `relogio`, `envelope`, `check`, `seta`, `mais`.
- Afeto e humor: `coracao`, `estrela`, `sorriso`.
