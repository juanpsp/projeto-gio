# Rabiscos

Elementos desenhados à mão em SVG, com cores fixas no arquivo. Os mais usados também existem como classes CSS (`.en-sublinhado`, `.en-circulado`, `.en-divisor`, `.en-estrelinha`, `.en-brilhos`, `.en-fita`).

- `sublinhado-onda`, `sublinhado-traco` (`rouge`): sob uma palavra-chave do título.
- `circulo-rabisco` (`rouge`): em volta de uma palavra; estique para caber.
- `seta-curva` (`encre`), `seta-laco` (`bleu`): ligam uma anotação em Caveat ao que ela comenta. Gire e espelhe à vontade.
- `brilhos` (`rouge`), `estrelinha` (`beurre` + `encre`): ênfase ao lado de títulos, selos e números.
- `forma-organica` (`ciel`): mancha atrás de fotos e ilustrações.
- `divisor-onda` (`bleu`, repete na horizontal), `divisor-bandeira` (`bleu`, `encre`, `rouge`): entre seções.
- `fita-adesiva` (`beurre` 80%): prende fotos e post-its.
