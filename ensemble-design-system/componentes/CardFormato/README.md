# Card de formato de aula

Card para cada formato de aula: etiqueta, título, descrição, lista com checks, detalhes e botão.

- `.en-card.en-card--formato` > `.en-tag` + `.en-card__titulo` + `.en-card__texto` + `ul.en-lista-check` + `.en-card__meta` + `.en-btn--bloco`.
- O formato em destaque ganha `.en-card--carimbo`, um `.en-adesivo--rouge` no canto ("Coup de cœur") e o botão primário; os outros usam botão contorno.
- O consumidor fornece: nome do formato, público, 3 itens de lista, duração e frequência (e preço, se quiser mostrar, dentro de `.en-card__meta`).
- Formatos, durações e frequências da prévia são exemplos.
