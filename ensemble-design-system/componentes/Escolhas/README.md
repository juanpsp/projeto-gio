# Escolhas

Opções em pílula (rádio) e caixas de seleção para perguntas rápidas no formulário.

- `fieldset.en-escolhas` com `legend` e `label.en-escolha` > `input[type=radio]` + `span`. A opção marcada fica azul e dá uma inclinadinha.
- `label.en-check` > `input[type=checkbox]` + texto, para consentimentos e opt-ins.
- 2 a 5 opções curtas. Exemplos de nível: "Nunca estudei", "Sei o básico", "Me viro", "Quero fluência".
