# Selo

Selos redondos de efeito: estrela de pontas para novidades e o selo giratório com o lema da marca.

- `.en-selo` (padrão `beurre`, `--rouge`, `--bleu`, `--grande`) com até 3 palavras; `<small>` adiciona uma linha em Caveat.
- `.en-selo-giratorio`: SVG com `textPath` circular + `.en-selo-giratorio__centro` com um ícone. Gira devagar e para com `prefers-reduced-motion`. Use no topo da página ou perto da foto da professora, uma vez.
- No máximo um selo por tela.
- Exemplos: "Nouveau!", "C'est parti!", "Sem medo de errar", "On apprend ensemble •".
