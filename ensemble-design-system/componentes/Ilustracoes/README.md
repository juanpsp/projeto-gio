# Ilustrações

Quatro ilustrações pequenas, com humor, que brincam com as referências francesas sem cair no clichê.

- `croissant-piscando`: boas-vindas, estados vazios, "pausa café".
- `torre-de-boina`: a Torre Eiffel usando boina. Bloco de destaque, rodapé, página 404.
- `balao-travei`: balão com o pensamento embolado, o momento de "travar". Seções sobre medo de falar, FAQ.
- `caderno-seyes`: caderno escolar francês (pauta Seyès) com um erro riscado e um acerto. Metodologia, erros comuns.
- Arquivos em `assets/Ilustracoes/` (SVG, 120×120). Use com `.en-ilustracao` (120px) ou `--sm` (72px). No máximo uma ilustração por seção.
