# Link

Texto azul sublinhado que vira um rabisco vermelho ondulado no hover.

- `.en-link` no meio do texto; `.en-link--seta` para links de ação soltos ("Ver os formatos →"); `.en-link--inverso` sobre fundos `bleu`.
- O texto do link diz para onde vai: "Eu conto aqui", "Ver os formatos". Nunca "clique aqui".
- Em fundo escuro use sempre `.en-link--inverso` (branco com sublinhado `beurre`).
