# Adesivo

Adesivo inclinado com contorno e sombra chapada, como se fosse colado no caderno.

- `.en-adesivo` (padrão `beurre`), `--rouge`, `--bleu`, `--blanc`, `--ciel`. Inclinação: padrão -4°, `--dir` +3°, `--reto`. No hover ele vira para o outro lado.
- Texto em Caveat por padrão (exclamações curtas); `--titulo` usa Fredoka para frases um pouco maiores, com ícone.
- Para colar em cima de outro elemento, posicione com `position: absolute` (veja o card de formato).
- Exemplos: "Oh là là!", "C'est parti!", "Bonjour!", "Zéro stress", "Merci!", "a gente aprende junto".
