# Etiqueta

Pílula pequena para categorizar: nível, modalidade, duração, tema.

- `.en-tag` (azul, padrão), `--rouge`, `--beurre`, `--neutra`, `--contorno`, `--solida`; `--ponto` adiciona uma bolinha. Aceita um ícone de 16px antes do texto.
- Uma ou duas palavras. Não é botão: não use etiqueta clicável sem estado de foco.
- Exemplos: "A1–A2", "Online", "Iniciante", "Conversação", "Gramática sem drama".
