# Capa

A capa do design system: o nome Ensemble em Fredoka sobre o ritmo azul–papel–vermelho da bandeira, com as pílulas de conversa no meio.

- Serve como referência de composição (blocos de cor grandes + uma trama de pílulas), não como componente de página.
- Se o nome da marca mudar, atualize o `<h1 class="name">` e o tamanho da fonte (o nome deve caber em ~440px).
