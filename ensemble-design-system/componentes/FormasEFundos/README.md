# Formas e fundos

Manchas orgânicas para colocar atrás de fotos e ilustrações, e o fundo de caderno francês para blocos especiais.

- `.en-forma` (ciel), `--beurre`, `--rose`; `--anima` faz a mancha "respirar" devagar (desliga com movimento reduzido). Defina a largura; a altura segue a proporção.
- `.en-fundo-caderno`: pauta Seyès das escolas francesas, com margem vermelha. Use em um bloco por página (ex.: "minha história com o francês") com texto em Caveat ou Figtree; deixe ~70px à esquerda para a margem.
- Formas ficam atrás do conteúdo e nunca carregam texto pequeno.
