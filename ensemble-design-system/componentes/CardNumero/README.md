# Card de número

Número grande em Fredoka com rótulo e uma anotação à mão que tira a seriedade do número.

- `.en-card.en-card--numero` > `.en-numero` + `.en-card__rotulo` + `.en-nota` opcional. Tons: padrão, `--ciel`, `--beurre`, `--carimbo`; `--rouge` deixa o número vermelho.
- Use só números reais (anos dando aula, alunos, alunos ativos); os da prévia são exemplos.
- 3 ou 4 cards lado a lado no máximo. Um card engraçado ("0 julgamentos por erro") é bem-vindo, mas só um.
