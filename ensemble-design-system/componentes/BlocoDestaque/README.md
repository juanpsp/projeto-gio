# Bloco de destaque

Faixa colorida de cantos bem redondos para chamadas: CTA de meio e fim de página, frases de impacto.

- `.en-destaque` (azul, padrão), `--beurre`, `--ciel`. Partes: `.en-nota` (chamada à mão acima do título), `.en-destaque__titulo`, `.en-destaque__texto`, `.en-destaque__acoes`, `.en-destaque__forma` (mancha orgânica decorativa no canto).
- No azul: botão `--primario` + `.en-link--inverso` ou `.en-btn--claro`. No beurre e no ciel: botão `--secundario`.
- Um bloco azul por página (o CTA final). Os outros tons podem aparecer mais.
- Pode levar uma ilustração ao lado do texto; no celular ela desce para baixo.

**Microtextos:** "sem pressão, prometo" / "Bora destravar esse francês?" / "travou numa palavra? Normal. A gente destrava junto."
