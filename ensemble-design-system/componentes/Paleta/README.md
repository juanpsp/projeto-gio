# Paleta

Mostra as cores da marca, onde cada uma entra e quais combinações de texto e fundo estão aprovadas.

- **Proporção por tela:** ~70% `papier`/`blanc`, ~20% `encre` e `bleu`, ~10% `rouge`/`rouge-action` e `beurre`. Se a tela parece uma bandeira, tem cor demais.
- **Texto:** sempre `encre` (ou `encre-douce` para apoio) sobre as cores claras; `texte-inverse` sobre `bleu`, `rouge-action` e `encre`.
- **Vermelho:** `rouge` (#EF4135) é o da bandeira e fica para rabiscos, adesivos, ícones e texto de 24px ou mais. Botões e texto vermelho pequeno usam `rouge-action`.
- **Nunca:** texto pequeno em `rouge`; texto branco em `rouge` ou `beurre`; `bleu` sobre `rouge` (vibra e perde leitura).
