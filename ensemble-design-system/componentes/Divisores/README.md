# Divisores

Separadores de seção desenhados à mão.

- `hr.en-divisor` (onda azul, largura toda), `--curto` (240px), `--bandeira` (traço azul, ponto, traço vermelho: a bandeira sem ser literal), `--estrelas` (linha com estrelinha no meio), `--rabisco` (traço duplo em encre).
- `.en-borda-onda`: borda ondulada em `papier-fonce` para a transição entre uma seção `papier` e uma `papier-fonce`.
- Prefira separar seções por espaço (`espaco-9`) e troca de fundo; divisor é pontuação, não parede.
